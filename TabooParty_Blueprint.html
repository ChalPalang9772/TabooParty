TABOO PARTY

Technical First Principles Blueprint

1. The Fundamental Problem

We are building a Stateless Web App that behaves like a Stateful Console Game. To achieve this, we split the universe into two parts:

THE BODY (Vercel)

Frontend / React / Next.js

--- Socket.io --->
THE BRAIN (Render)

Backend / Node.js / Server

When you guess a word on your phone, it travels to the Brain, which updates the State, and then screams the result back to every Body connected.

2. The Invisible Wire (Connection)

The biggest reason for "Reconnecting" errors is that the Body doesn't know where the Brain is. We fix this with an Environment Variable.

// src/lib/socket.ts
const SOCKET_URL = process.env.NEXT_PUBLIC_SOCKET_URL || 'http://localhost:3001';

First Principle: At build-time, Vercel replaces `process.env.NEXT_PUBLIC_SOCKET_URL` with your Render URL. If this variable is missing or wrong, it defaults to `localhost`, which fails on mobile devices.

3. The Architecture (From Scratch)

  • 1
    The Engine (`src/lib/engine.ts`): Contains the "Physics" of the game. How words are chosen, how many points you get, and when the timer expires. It is purely mathematical and doesn't know about the internet.
  • 2
    The Server (`server/index.ts`): The gatekeeper. It uses Socket.io to manage "Rooms". It listens for events like guess:submit and responds with guess:result.
  • 3
    The Store (`src/lib/store.ts`): The client's memory. We use Zustand to keep a local copy of the game state so the UI updates instantly.

4. The "Deep Fix" Checklist

If you are still seeing "Reconnecting", follow these steps in order:

  • Check the Render Type: Ensure your backend is a "Web Service". If you created a "Static Site" on Render, the backend will never run.
  • Check CORS (The Security Gate): In server/index.ts, we set origin: '*'. This tells the server to talk to anyone. Check your Render Logs to see if there are any "CORS" errors.
  • Check the URL Protocol: Your Vercel link is https://. Your Render link must also be https://. Using http:// will cause the browser to block the connection.
  • The Hard Refresh: On your phone, clear your browser cache or open the game in an Incognito/Private tab to ensure it's not using an old version of the site.

5. The Key Files Reference

  • Backend Build: npm run dev:server (Uses tsx to run TypeScript directly).
  • Frontend Build: npm run build (Generates optimized HTML/JS).
  • Deployment: render.yaml (The blueprint for one-click setup).
